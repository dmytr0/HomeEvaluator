🏆 Результати порівняння

⚙️ Налаштування вагових коефіцієнтів

ℹ️ Як працює система ваг

Кожен параметр має ваговий коефіцієнт. Чим вищий коефіцієнт, тим важливіший параметр для фінального балу.

Формула: (сума вагових балів) / (сума всіх ваг) × 100

Якщо параметр не вказано: він отримує значення за замовчуванням (False для булевих, 0 для числових, перший варіант для вибору).

Приклад: Якщо ви хочете, щоб ціна була найважливішою, збільште її вагу до 30-40.

Основні параметри

➕ Додати новий параметр

ℹ️ Як додати новий параметр

1. Введіть назву параметра (наприклад: has_pool, energy_efficiency)

2. Вкажіть вагу (наскільки важливий цей параметр)

3. Оберіть тип параметра:

  • Логічний (так/ні): Параметр типу так/ні (наприклад, наявність басейну)
  • Числовий: Числове значення (наприклад, рейтинг енергоефективності)
  • Вибір зі списку: Оберіть з декількох варіантів

4. Після додавання, параметр з'явиться у формі додавання будинку
